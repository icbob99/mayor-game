# Mayor Game — Roadmap развития

## Игра сейчас

[Играть в Mayor Game](https://icbob99.github.io/mayor-game/)

Мэр принимает решения на карточках: каждый выбор меняет деньги, здоровье, отношения с женой, угрозу полиции и поддержку жителей. Цель — дольше удержаться у власти и накопить капитал. Магазин помогает улучшать показатели.

- Можно играть гостем с сохранением в браузере или зарегистрироваться по нику и паролю.
- У мэра есть облачное сохранение, история и достижения; игру можно продолжить на другом устройстве. Гостевой прогресс хранится отдельно.
- Доступны русский, английский, украинский и иврит; язык и звук запоминаются.

## Как размещена игра

- **GitHub Pages** — сайт из ветки `master`; игровая логика работает в браузере.
- **Cloudflare Worker `mayor-game-api`** — API между браузером и БД. Новую загруженную версию публикуем через **Deployments → Promote**, возврат — **Rollback**.
- **Turso `mayor-game-db`** — игровые тексты, аккаунты и сохранения. SQL-изменения применяются отдельно.
- **Docker** — локальный тестовый стенд, в production не используется.

## Фаза 3 — Аудио и музыкальная система

Текущая фоновая музыка на Web Audio API заменяется на полноценную музыкальную систему.

До реализации нужно определить:

- новую музыкальную тему и формат аудиофайлов;
- громкость музыки и звуковых эффектов отдельно;
- повтор фоновой музыки без резких переходов;
- поведение после перезагрузки страницы;
- сохранение настроек звука и музыки в гостевой и зарегистрированной игре.

## Фаза 4 — Полноценная регистрация и управление доступом

Развить простую регистрацию 1B для полноценной публичной эксплуатации. Требования и технические решения определяются отдельным дизайном. Эта фаза не блокирует простую регистрацию 1B.
