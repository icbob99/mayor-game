# Mayor Game - Balance and Card Rules

> Working table for manual balance changes. Effect columns are the source of truth for the next seed update.

## Rules

- `TBD`: set manually.
- `unlimited`: may appear repeatedly during a cycle.
- `once`: at most once per cycle.
- `twice`: at most twice per cycle.
- `follow-up`: never selected by normal random selection; triggered by another card.
- Choice numbering starts at 1.
- Monetary hints were removed from choice text; money is shown in the `Money` column.
