# Mayor: Chronicles of Embezzlement

A satirical browser game about a mayor balancing money, family, health and public support while avoiding arrest.

[Play the game](https://icbob99.github.io/mayor-game/)

## Run the local test stack

Requires Python 3 and Docker Desktop running Linux containers. From the repository directory:

```powershell
python server.py
```

After `Ready` appears, open [localhost:8787](http://localhost:8787).
Each launch recreates the stack and resets its database and local game saves.
